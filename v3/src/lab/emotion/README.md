# Emotion Lab

Ізольована dev-пісочниця для перевірки статичних поз стаканчика, кольорів,
процедурного обличчя та силуетного режиму до інтеграції в застосунок.

## Запуск

```text
npm run dev
http://127.0.0.1:5174/?lab=emotion
```

Маршрут доступний лише в development. Код лабораторії та її GLB-моделі не
потрапляють у production bundle.

## Що можна перевіряти

- п'ять статичних поз: `neutral`, `wave`, `present`, `celebrate`, `wait`;
- готові емоції та ручне налаштування очей і рота;
- напрямок, у якому шейдер малює обличчя;
- палітри та окремі кольори матеріалу;
- межі кришки, корпусу, рукава й процедурну маску рук;
- білий силует для майбутніх переходів;
- ракурс, масштаб і світло;
- експорт поточного стану кнопкою `Скопіювати preset JSON`.

Налаштування зберігаються тільки в `localStorage` поточного браузера. Лабораторія
не викликає API, не читає базу даних і не змінює стан основного застосунку.

## Додавання нової пози

1. Покласти оптимізований `.glb` у `assets/`.
2. Додати імпорт і URL у `types.ts`.
3. Додати кнопку пози в `EmotionLab.tsx`.
4. Перевірити модель у всіх пресетах обличчя, в силуеті та на вузькому екрані.

## Важливе обмеження поточних GLB

Усі п'ять моделей мають один mesh і один material, а їхня топологія відрізняється.
Тому між позами не можна робити надійний vertex morph. Для цих активів
лабораторія будує окрему маску рук для кожної пози з компактних зв'язаних частин
геометрії; це не дає фарбі переходити на корпус і не дозволяє обличчю малюватися
на долоні. Для нових моделей усе одно краще експортувати окремі material slots
або стабільні vertex colors: тоді додаткова маска взагалі не знадобиться.
